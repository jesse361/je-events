# J&E Events

A Next.js site for J&E Events. Events, speakers, venues, prices, and partner marks in the interface are sample content.

```bash
npm run dev
```

Open the URL printed by the dev server.

Set `NEXT_PUBLIC_SITE_URL` to the production origin when you have one. That enables absolute Open Graph URLs and the sitemap. Newsletter, contact, and ticket forms do not send data anywhere until an email service or payment provider is connected.
